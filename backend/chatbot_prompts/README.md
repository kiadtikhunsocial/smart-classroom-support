# จุดปรับพฤติกรรมแชตบอต

- `backend/chatbot_extra_prompt.txt`: น้ำเสียงเริ่มต้นที่ deploy มาพร้อมโค้ด; หน้าเว็บมีช่อง `global_style` สำหรับเพิ่มแนวทางร่วมแบบแก้ไขได้ทันที
- หน้า “จัดการ AI / LINE OA” (owner/super_admin): เพิ่มคำถาม–คำตอบที่ตรวจสอบแล้วลง DB และแก้คำแนะนำแยกตามงาน; แท็บผลประเมินเปิดเฉพาะบัญชี `super_admin` ที่มีชื่อ `iwasuperadmin` (เปลี่ยนชื่อบัญชีที่อนุญาตได้ด้วย `RATINGS_VIEWER_USERNAME` บน backend)
- ไฟล์ `.txt` ในโฟลเดอร์นี้: ค่าเริ่มต้นของคำแนะนำเฉพาะงาน เมื่อยังไม่เคยบันทึกค่าของงานนั้นใน DB
- `backend/app/assistant_policy.py`: กฎความปลอดภัย การอ้างอิงข้อมูล และป้องกัน prompt injection **ห้ามย้ายไปไฟล์คำแนะนำ**
- `backend/app/gemini_service.py`: เส้นทาง AI สำหรับจำแนกเจตนา จับข้อมูล จับคู่ KB และร่างคำตอบ
- `backend/app/line_bot.py`: LINE OA และ fallback; `line_reply.txt` เพิ่มคำแนะนำเฉพาะข้อความ LINE
- บทความวิธีแก้ให้แก้ในหน้า “ฐานความรู้แชตบอต”; ราคา/สินค้าให้แก้แค็ตตาล็อกจริง ไม่ใช่ prompt

คำถาม–คำตอบที่เพิ่มในหน้าเว็บใช้เฉพาะคำถามทั่วไปที่ตรงกันแบบ exact match หลังจัดรูปแบบข้อความ; ห้ามใช้แทนข้อมูลราคา ประกัน การชำระเงิน หรือ Ticket ที่ต้องอ่าน DB สด คำตอบต้องตรวจและกดเผยแพร่ก่อน LINE ใช้ได้

ขั้นตอนแนะนำ: บันทึกฉบับร่าง → ทวนความถูกต้อง → เผยแพร่ → ทดสอบคำถามจริงใน LINE และคำถามกำกวม/อันตราย/หลอกให้เปิด prompt คำแนะนำ AI ที่บันทึกใน DB มีผลกับคำถามใหม่ทันทีโดยไม่ต้อง deploy แต่การเปลี่ยน prompt ไม่ใช่การฝึกโมเดล และห้ามใช้เพื่อแก้ข้อมูลจริงใน DB
