# คู่มือการใช้งาน Smart Classroom Support

## สำหรับผู้แจ้งซ่อม (ครู / นักเรียน / เจ้าหน้าที่)

### แจ้งซ่อมด้วยการสแกน QR
1. สแกน QR ที่ติดกับตัวอุปกรณ์ (ด้วยกล้องมือถือ หรือแอปสแกน QR)
2. เบราว์เซอร์จะเปิดหน้าแจ้งซ่อม พร้อมข้อมูลอุปกรณ์/ห้องเติมให้อัตโนมัติ
3. กรอกหัวข้อ/อาการ (เช่น "จอไม่ติด", "Wi-Fi ไม่เข้า") แล้วกดส่ง
4. ได้หมายเลข Ticket (รูปแบบ `SC-2026-XXXXXX`) เก็บไว้ติดตาม

> **ไม่ต้องมีบัญชี** — สแกน QR แจ้งซ่อมได้ทันที
> ถ้าเครื่องนี้มีงานค้างอยู่ ระบบจะเตือน (กันแจ้งซ้ำ) และให้กดดูสถานะงานเดิมได้

### ใช้ AI ช่วยวินิจฉัยเบื้องต้น
- บนฟอร์มแจ้งซ่อม กดปุ่ม **"🤖 ทดลองวินิจฉัยอัตโนมัติ"** หลังกรอกอาการ
- ระบบค้นหาวิธีแก้จากฐานความรู้ (KB) — ถ้าเจอจะแสดงขั้นตอนให้ลองทำ
- กด **"แก้ไขได้แล้ว ✅"** ถ้าทำได้เอง (บันทึกเป็น Self-Service) หรือ **"ยังไม่หาย → แจ้งเจ้าหน้าที่"** เพื่อสร้าง Ticket

### ติดตามสถานะงาน
- **มีบัญชี:** เข้าสู่ระบบ → หน้า Dashboard/ตาราง Tickets เห็นงานของตัวเอง
- **ไม่มีบัญชี:** หน้า login กด "ติดตามสถานะโดยไม่ต้องเข้าสู่ระบบ" → กรอกเลข Ticket → เห็นความคืบหน้า
- **ลืมเลข Ticket:** สแกน QR ที่เครื่องเดิมอีกครั้ง → จะเห็น "งานแจ้งซ่อมล่าสุดของเครื่องนี้" พร้อมเลข + ปุ่มดูสถานะ

### เปลี่ยนธีม (มืด/ม่วง/น้ำเงิน)
- เข้าสู่ระบบ → เมนู **"การตั้งค่า"** (ทุกบทบาทมี) → เลือกธีม
- ธีมจะจำไว้ในเบราว์เซอร์ที่ใช้ (เปลี่ยนเครื่องต้องตั้งใหม่)

## สำหรับเจ้าหน้าที่ IT / ช่าง

### รับงานและซ่อม
1. เข้าสู่ระบบด้วยบัญชี it_support/admin → เมนู **Tickets**
2. เปิด Ticket ที่สถานะ `รอรับเรื่อง` → **รับงาน** (กลายเป็น in_progress)
3. เมื่อซ่อมเสร็จ → **บันทึกผล** (สาเหตุ/วิธีแก้) → สถานะเป็น `resolved`
4. รอผู้แจ้งกดยืนยันปิดงาน (หรือ admin ปิดให้)

### ทำ Preventive Maintenance (PM)
- เมนู **บำรุงรักษา** → แท็บ "งาน" → กด **⚡ สร้างงานล่วงหน้า** เพื่อสร้างงานจากแผนให้อุปกรณ์ที่ถึงรอบ
- เปิดงาน PM → ติ๊กรายการตรวจ (ผ่าน/ไม่ผ่าน) + ถ่ายรูป → บันทึก
- ถ้ามีรายการ "ไม่ผ่าน" ระบบจะ**สร้าง Ticket ซ่อมให้อัตโนมัติ**

### จัดการอุปกรณ์
- เมนู **อุปกรณ์** → เพิ่ม/แก้ไข/ลบอุปกรณ์, สร้าง QR (ปุ่ม QR), จัดการห้อง (dropdown + ปุ่ม ＋)
- หน้า **พิมพ์ QR** — สั่งพิมพ์ QR เป็นชุด

## สำหรับผู้ดูแลระบบ (admin / super_admin)

### จัดการโรงเรียน (super_admin)
- เมนู **โรงเรียน** — เพิ่ม/ลบโรงเรียน, ดูสถิติรายโรงเรียน

### จัดการผู้ใช้
- เมนู **Users** — สร้าง/แก้ไข/ลบผู้ใช้, ตั้งบทบาท, ตั้ง/รีเซ็ตรหัสผ่าน, เปิด-ปิดบัญชี

### จัดการฐานความรู้ (KB)
- เมนู **ฐานความรู้** — ดู/เพิ่ม/แก้ไขบทความวิธีแก้ไข, เผยแพร่/ยกเลิก

### ดูรายงาน
- เมนู **Reports** — ภาพรวม, สถิติปัญหา, อุปกรณ์ที่เสียบ่อย

### แก้ไขโปรไฟล์/รหัสผ่านตัวเอง
- เมนู **โปรไฟล์** หรือ **การตั้งค่า** → แก้ไขบัญชี
