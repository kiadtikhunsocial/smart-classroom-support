# ดูแลแชตบอต IWA

แชตบอตมี 3 ส่วนที่แยกหน้าที่กัน: `chatbot_nlu.py` จับเจตนา, `chatbot_core.py` คุมลำดับสนทนาและงานที่เขียนข้อมูล, `gemini_service.py` ช่วยตีความ/เลือกบทความแบบ opt-in. คำตอบด้านราคา สถานะงาน และวิธีแก้ต้องอิงข้อมูลจริง ไม่ใช่ให้ AI แต่งขึ้นเอง

## เจ้าหน้าที่ปรับคำตอบโดยไม่แก้โค้ด

1. เปิด **ฐานความรู้แชตบอต** ใน Dashboard. ใช้ **ดูคำถามที่บอตตอบไม่ชัด** เพื่อหาเรื่องที่ควรทบทวน (เฉพาะผู้ดูแลระดับระบบ; ข้อมูลส่วนบุคคลถูกปิดบังบางส่วน)
2. เพิ่มบทความพร้อมหัวข้อ ประเภทอุปกรณ์ คำค้นหลายรูปแบบ และขั้นตอนแก้ที่ตรวจสอบแล้ว. เริ่มด้วย **ยังไม่เผยแพร่**. ห้ามใส่ขั้นตอนถอดฝา/แตะระบบไฟฟ้าที่เสี่ยง
3. ให้ผู้รับผิดชอบทวนความถูกต้อง แล้วเปิด **เผยแพร่**. บทความที่ยังไม่เผยแพร่ไม่ควรถูกใช้เป็นคำตอบจริง
4. คำถามที่ปรากฏในรายการ “ควรตรวจ” ไม่ได้หมายความว่าบอตผิดเสมอ; ต้องอ่านบริบทและตรวจข้อมูลจริงก่อนเพิ่มความรู้

ข้อมูลสินค้า/ราคา/บริการขณะนี้อยู่ที่ `backend/app/company_catalog.py` และยังต้องแก้ผ่านโค้ดกับ review ก่อน deploy. อย่าใส่ราคาในบทความซ่อมเพื่อเลี่ยงแหล่งข้อมูลซ้ำกัน. ข้อมูลลูกค้าหรือรหัสผ่านไม่ควรใส่ในฐานความรู้

## ปรับ prompt เพิ่มเติมด้วยตัวเอง

แก้ไฟล์ `backend/chatbot_extra_prompt.txt` เพื่อปรับน้ำเสียงและแนวทางการถามตอบ โดยไม่ต้องแก้ไฟล์ Python. หลังแก้ให้รันชุดทดสอบและ deploy backend ใหม่จึงจะมีผลกับ Gemini/LINE. ข้อความในไฟล์นี้เป็นคำแนะนำรอง: กฎความปลอดภัยและข้อเท็จจริงจากฐานความรู้/ฐานข้อมูลยังมีลำดับเหนือกว่า. **อย่าใส่ API key, รหัสผ่าน, ข้อมูลลูกค้าจริง, ราคา หรือข้อความที่สั่งให้ข้ามกฎ**. การเพิ่มวิธีซ่อมที่ตรวจสอบแล้วให้ทำในหน้า “ฐานความรู้แชตบอต” แทน

## ตรวจคุณภาพก่อน deploy

จากโฟลเดอร์ `backend` รัน:

```powershell
.\.venv\Scripts\python.exe -m pytest tests/test_chatbot_nlu.py tests/test_chatbot_quality.py test_chatbot_guardrails.py -q
```

เมื่อพบคำถามที่ตอบผิด ให้เพิ่มข้อความตัวอย่างและผลที่คาดหวังใน `tests/test_chatbot_quality.py` ก่อนปรับกฎ. ชุดนี้เป็น offline regression; **ไม่ได้เรียก Gemini หรือ LINE และไม่ได้พิสูจน์คุณภาพคำตอบของโมเดลสด**. การเปลี่ยน prompt/model ต้องตรวจในสภาพแวดล้อมทดสอบด้วยคนก่อนเปิด production

ตัวแปร `ENABLE_GEMINI_CLASSIFIER`, `ENABLE_GEMINI_ORCHESTRATION` และ `ENABLE_GEMINI_NATURAL_REPLIES` เป็น opt-in. ถ้าไม่มี API key หรือ AI ขัดข้อง ระบบควรกลับไปใช้กฎ/ฐานความรู้เดิม. Freeform AI ใช้เพียงการทักทาย/ขอบคุณ; ข้อเท็จจริงทางธุรกิจและวิธีซ่อมต้องมาจาก catalog, KB หรือ backend. การ “เทรน” ในระบบนี้หมายถึงปรับฐานความรู้ กฎ และชุดทดสอบ ไม่ใช่ fine-tune โมเดล Gemini
